## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/nasim-dev0459/Machine-Learning---Data-Mining-Essentials.git
```

Navigate into the project:

```bash
cd Machine-Learning---Data-Mining-Essentials
```

Install dependencies:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```
